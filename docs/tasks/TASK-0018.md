# TASK-0018: Migrate from Google Fonts to Bunny Fonts

## Goal

Replace the Google Fonts CDN references in `src/index.html` with equivalent
**Bunny Fonts** CDN references. Bunny Fonts is a privacy-oriented, GDPR-compliant
drop-in alternative that serves the same font files (including Inter) without
tracking end-users.

No visual change is expected — the rendered font must remain **Inter** at the
same weights (400, 500, 600, 700) with `display=swap`.

---

## Relevant prior decisions

- **DEC-0005** — Inter is the application's UI font; the weight set and `display=swap`
  strategy must be preserved exactly.
- No business logic is involved; **DEC-0001 unit-test requirement does not apply**
  to this task.
- No JavaScript modules are introduced or modified.

---

## Section-by-section specification

### 1  Changes to `src/index.html`

Locate the three Google Fonts lines currently in `<head>`:

```html
<link rel="preconnect" href="https://fonts.googleapis.com" />
<link rel="preconnect" href="https://fonts.gstatic.com" crossorigin />
<link rel="stylesheet" href="https://fonts.googleapis.com/css2?family=Inter:wght@400;500;600;700&display=swap" />
```

Replace them with the Bunny Fonts equivalents:

```html
<link rel="preconnect" href="https://fonts.bunny.net" />
<link rel="stylesheet" href="https://fonts.bunny.net/css?family=inter:400,500,600,700&display=swap" />
```

Notes:
- Bunny Fonts uses a single preconnect host (`fonts.bunny.net`); there is no
  separate resource host, so the `fonts.gstatic.com` preconnect is removed.
- The family name is lowercase (`inter`) in the Bunny Fonts API.
- Weight values are comma-separated integers rather than the Google Fonts
  `wght@…` syntax.
- `display=swap` is preserved as-is.

---

## Implementation steps

1. Open `src/index.html` and replace the three Google Fonts `<link>` tags with
   the two Bunny Fonts tags shown in §1.
2. Serve the app with `make serve` and confirm:
   - The Inter font loads correctly (check DevTools → Network → Fonts).
   - No requests are made to `fonts.googleapis.com` or `fonts.gstatic.com`.
   - The visual appearance of the application is unchanged.
3. Run `make test` to confirm no regressions.
4. Update `docs/progress.md` with a TASK-0018 entry.
