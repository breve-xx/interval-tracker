# TASK-0019: Add MIT Licence to the Project

## Goal

Formally licence the project under the **MIT Licence** by:

1. Creating a `LICENSE` file in the repository root.
2. Updating the `"license"` field in `package.json` from `"ISC"` to `"MIT"`.
3. Adding a `## Licence` section to `README.md`.

No source files in `src/` or `tests/` are modified.

### Scope rationale — where licence information belongs

| Location | Decision | Reason |
|---|---|---|
| `LICENSE` file | **Required** | Canonical legal artefact; GitHub surfaces it automatically as a repo badge. |
| `README.md` | **Required** | First place a developer visits; a `## Licence` section is universal convention for open-source projects. |
| App footer (`index.html`) | **Omitted** | The footer targets end-users of the web app, not code consumers. The existing "open source interval analysis" copy already signals openness; adding a licence name would be noise without benefit. |
| Source file SPDX headers | **Omitted** | Useful in large multi-contributor codebases. Adds maintenance overhead with no practical gain for a small single-repo project. |

## Dependency licence analysis

Before selecting a licence the external dependencies were audited. The table
below records every dependency and the licence that governs it.

### npm packages (all `devDependencies`)

| Package | Role | Licence |
|---|---|---|
| `vite` | Build / dev server | MIT |
| `vitest` | Test runner | MIT |
| `@vitest/coverage-v8` | Coverage provider | MIT |
| `jsdom` | DOM environment for tests | MIT |

### CDN runtime assets

| Asset | Source | Licence |
|---|---|---|
| Lucide Icons UMD bundle | `unpkg.com/lucide` | ISC (+ MIT for the Feather-derived icon subset) |
| Inter typeface | `fonts.bunny.net` (after TASK-0018) | SIL Open Font Licence 1.1 (OFL-1.1) |

### Licence compatibility rationale

- All npm packages are **MIT**, the most permissive OSI-approved licence.
- Lucide Icons is **ISC**, which is functionally equivalent to MIT (permissive,
  no copyleft, attribution only).
- The Inter font is **OFL-1.1**. The OFL explicitly states: *"The requirement
  for fonts to remain under this license does not apply to any document created
  using the Font Software."* Accordingly, OFL-1.1 imposes **no restrictions on
  the application code** that merely loads the font via a CDN `<link>` tag.

**Conclusion**: no dependency introduces a copyleft obligation. The project's
own code may be licensed under any permissive licence. **MIT** is chosen over
ISC (the current `package.json` placeholder) because it is more widely
recognised, better understood by consumers, and universally considered
compatible with ISC and OFL-1.1.

## Section-by-section specification

### 1  `LICENSE` file (repository root)

Create a new file at the repository root named `LICENSE` (no extension) with
the following content, replacing `<YEAR>` with the current year and
`<AUTHOR>` with the project author name (or the GitHub organisation/username
if the author field in `package.json` is empty):

```
MIT License

Copyright (c) <YEAR> <AUTHOR>

Permission is hereby granted, free of charge, to any person obtaining a copy
of this software and associated documentation files (the "Software"), to deal
in the Software without restriction, including without limitation the rights
to use, copy, modify, merge, publish, distribute, sublicense, and/or sell
copies of the Software, and to permit persons to whom the Software is
furnished to do so, subject to the following conditions:

The above copyright notice and this permission notice shall be included in all
copies or substantial portions of the Software.

THE SOFTWARE IS PROVIDED "AS IS", WITHOUT WARRANTY OF ANY KIND, EXPRESS OR
IMPLIED, INCLUDING BUT NOT LIMITED TO THE WARRANTIES OF MERCHANTABILITY,
FITNESS FOR A PARTICULAR PURPOSE AND NONINFRINGEMENT. IN NO EVENT SHALL THE
AUTHORS OR COPYRIGHT HOLDERS BE LIABLE FOR ANY CLAIM, DAMAGES OR OTHER
LIABILITY, WHETHER IN AN ACTION OF CONTRACT, TORT OR OTHERWISE, ARISING FROM,
OUT OF OR IN CONNECTION WITH THE SOFTWARE OR THE USE OR OTHER DEALINGS IN THE
SOFTWARE.
```

### 2  `package.json`

Change the `"license"` field from `"ISC"` to `"MIT"`:

```json
"license": "MIT",
```

### 3  `README.md`

Append a `## Licence` section at the end of `README.md`:

```markdown
## Licence

MIT — see [LICENSE](LICENSE) for the full text.
```

The section must come after the existing `## Tech Stack` section, separated by
a `---` horizontal rule, consistent with the style of the rest of the file.

## Implementation steps

1. Create `LICENSE` at the repository root using the template in §1.
   Fill in the current year and the author name.
2. Edit `package.json`: change `"license": "ISC"` → `"license": "MIT"`.
3. Append the `## Licence` section to `README.md` as specified in §3.
4. Run `make test` to confirm no regressions.
5. Update `docs/progress.md` with a TASK-0019 entry, including the dependency
