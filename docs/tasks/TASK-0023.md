# TASK-0023: Fix Off-Centre Waveform in favicon.svg

## Goal

The waveform path in `src/favicon.svg` is neither horizontally nor vertically
centred within the 32 × 32 viewBox. Two distinct defects are present:

1. **Horizontal asymmetry** — the path spans x = 2 to x = 24.5, placing its
   visual centre at x ≈ 13.25 instead of x = 16.
2. **Vertical asymmetry** — the peak sits 10.5 px above the midline (y = 5.5)
   while the trough sits only 10 px below (y = 26), and the final flat segment
   lands at y = 15.5 instead of y = 16.

The fix is a pure SVG change: redraw the path so the waveform is perfectly
symmetric around both axes of the canvas centre (16, 16).

No JavaScript, CSS, HTML, or test changes are required. Coverage is unaffected.

---

## Root cause analysis

### RC-01 — Incorrect starting x-coordinate and unequal horizontal span

**File:** `src/favicon.svg:11`

```svg
<path class="fg" d="M2 16 h5 l3.5 -10.5 L16 26 l3.5 -10.5 h5"/>
```

The path starts at x = 2 (left margin = 2 px) but ends at x = 24.5
(right margin = 7.5 px). The horizontal span is 22.5 px centred at x ≈ 13.25.

### RC-02 — Mismatched peak and trough amplitudes

The peak is drawn at y = 5.5 (10.5 px above midline) and the trough at y = 26
(10 px below midline). Because the amplitudes differ, the final `l3.5 -10.5`
segment overshoots and lands at y = 15.5 rather than y = 16, leaving the right
flat segment visibly below the left one.

---

## Proposed path

Replace the existing path with one constructed from equal relative moves,
symmetric about (16, 16):

```
M4 16 h4 l4 -11 l8 22 l4 -11 h4
```

Keypoints:

| Point | x  | y  | Description            |
|-------|----|----|------------------------|
| Start | 4  | 16 | left flat start        |
| →     | 8  | 16 | left flat end          |
| Peak  | 12 | 5  | 11 px above midline    |
| Trough| 20 | 27 | 11 px below midline    |
| →     | 24 | 16 | right flat start       |
| End   | 28 | 16 | right flat end         |

Symmetry checks:
- Horizontal centre: (12 + 20) / 2 = **16** ✓
- Vertical centre: (5 + 27) / 2 = **16** ✓
- Left margin: 4 px; right margin: 32 − 28 = **4 px** ✓
- Both flat segments lie on y = **16** ✓
