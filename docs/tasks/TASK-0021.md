# TASK-0021: Per-Card Gap Display

## Goal

Show, directly on each occurrence card in the list, how much time elapsed
between that occurrence and the previous one. The gap must be expressed in
a human-readable, at-a-glance format (e.g. "3 days 4 h 12 m"). The very
first card (no prior occurrence) shows nothing in that slot.

## Specification

### `formatGap(ms)` — new export in `formatters.js`

Accepts a non-negative number of milliseconds and returns a compact
human-readable string. Rules:

| Duration | Output format | Example |
|---|---|---|
| < 60 seconds | `"< 1 m"` | any sub-minute gap |
| < 1 hour | `"{m} m"` | `"43 m"` |
| < 24 hours | `"{h} h {m} m"` | `"2 h 05 m"` — zero-pad minutes to 2 digits |
| ≥ 24 hours | `"{d} d {h} h {m} m"` | `"3 d 4 h 12 m"` — zero-pad minutes; omit hours when 0 only if days > 0 and hours === 0 (output `"{d} d {m} m"`) |

Edge case: if `ms` is `0` (two occurrences at the identical timestamp),
return `"0 m"`.

### Card rendering — `buildCardHTML` update

`buildCardHTML(iso, idx, prevIso)` gains an optional third parameter:

- `prevIso` (`string | null | undefined`) — the ISO string of the
  immediately preceding occurrence, already sorted chronologically.
- When `prevIso` is provided, compute `gap = new Date(iso) - new Date(prevIso)`
  and render `formatGap(gap)` inside a `<span class="occ-row__gap">` element.
- When `prevIso` is absent or falsy (first card), render an empty
  `<span class="occ-row__gap occ-row__gap--first"></span>`.

Update the `renderList` call site:

```js
listEl.innerHTML = records
  .map((iso, i) => buildCardHTML(iso, i + 1, records[i - 1] ?? null))
  .join('');
```

### HTML structure of a card (after change)

```html
<li class="occ-row" data-iso="…">
  <span class="occ-row__num">2</span>
  <span class="occ-row__datetime">
    <span class="occ-row__date">20/02/2026</span>
    <span class="occ-row__time">15:10</span>
  </span>
  <span class="occ-row__tell">The 20th of February at 15:10</span>
  <span class="occ-row__gap">3 d 4 h 12 m</span>
</li>
```

For the first card the gap span is empty (and carries the `--first` modifier
class so CSS can target it if needed — e.g. hide or show a placeholder dash).

### CSS (`styles.css`)

Add rules for `.occ-row__gap`:

- Render as a distinct visual block within the card (right-aligned, or on a
  second row — follow the existing card layout conventions).
- Use a muted colour (e.g. `var(--color-text-muted)` if the variable exists,
  otherwise a suitable fallback) and a slightly smaller font size so it reads
  as supplementary information.
- `.occ-row__gap--first` should visually hide the element or show a neutral
  placeholder (`—`) via CSS `content` on a `::before` pseudo-element, at the
  implementor's discretion.
